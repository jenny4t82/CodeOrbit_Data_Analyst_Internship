# Internship Data Analytics Projects

A collection of data analytics projects completed as part of my internship. This repository contains data cleaning, exploratory data analysis, and dashboard development projects using Python and Power BI.

## About the Repository

This repository documents my work across three data analytics tasks. Each project focuses on a different stage of the data analytics workflow, from preparing raw data to analyzing trends and presenting insights through visualizations.

## Projects

### Task 1: Cafe Sales Data Analysis

**Objective:** Clean and prepare cafe sales data for analysis.

**Work completed:**
- Explored the cafe sales dataset.
- Performed data cleaning and preprocessing.
- Prepared the dataset for further analysis.
- Documented the project and workflow.

**Tools:** Python, Pandas, Jupyter Notebook

**Project folder:** `Task_1_Cafe_Sales/`

---

### Task 2: Retail Sales Data Analysis

**Objective:** Analyze retail sales data to understand sales patterns and business performance.

**Work completed:**
- Explored and analyzed the retail sales dataset.
- Performed data analysis using Python.
- Examined sales-related trends and patterns.
- Created visualizations to support the analysis.
- Documented the findings and project workflow.

**Tools:** Python, Pandas, Matplotlib, Jupyter Notebook

**Project folder:** `Task_2_Retail_Sales/`

---

### Task 3: Superstore Sales Dashboard

**Objective:** Develop an interactive Power BI dashboard to summarize sales and profitability across categories, customer segments, and regions.

**Dashboard pages:**

**1. Sales Overview**
- Total Sales
- Total Orders
- Total Profit
- Profit Margin
- Monthly Sales Trend
- Sales by Category

**2. Profit Analysis**
- Profit by Category
- Profit by Region

**3. Regional Analysis**
- Customer Sales by Segment
- Sales vs. Profit by Category

**Tools:** Power BI Desktop

**Project folder:** `Task_3_Sales_Dashboard/`

## Getting Started

### Python Projects

1. Clone this repository:

   ```bash
   git clone https://github.com/jenny4t82/Internship_Data_Analytics.git
   ```

2. Navigate to the repository:

   ```bash
   cd Internship_Data_Analytics
   ```

3. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

4. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Open the relevant Jupyter Notebook in Jupyter Notebook or VS Code.

### Power BI Dashboard

1. Open Power BI Desktop.
2. Open `Task_3_Sales_Dashboard/Global_Superstore_Dashboard.pbix`.
3. If prompted, connect the report to the locally available Sample Superstore CSV dataset.
4. Navigate through the dashboard pages to explore sales and profitability.
