# Task 3: Superstore Sales Dashboard

## Project Overview

This project presents a sales dashboard built in Power BI Desktop using the Sample Superstore dataset. It summarizes sales and profitability across categories, customer segments, and regions.

## Objective

To visualize sales and profitability metrics and identify trends across categories, customer segments, and regions.

## Tool Used

- Power BI Desktop

## Dataset

The Sample Superstore dataset contains sales, customer, product, and regional information. The CSV files are kept locally for use with the Power BI report and are not included as committed project files because their license has not been confirmed.

## Dashboard Pages and Visualizations

### Page 1: Sales Overview

- Total Sales
- Total Orders
- Total Profit
- Profit Margin
- Monthly Sales Trend
- Sales by Category

### Page 2: Profit Analysis

- Profit by Category
- Profit by Region

### Page 3: Regional Analysis

- Customer Sales by Segment
- Sales vs. Profit by Category

## Key Metrics

- Total Sales
- Total Orders
- Total Profit
- Profit Margin

## Project Files

- `Global_Superstore_Dashboard.pbix` — Power BI dashboard
- `README.md` — Project documentation
- `data/Sample - Superstore.csv` — Local dataset used by the dashboard; not committed

## How to Open the Dashboard

Open `Global_Superstore_Dashboard.pbix` in Power BI Desktop. If Power BI prompts for the dataset location, select the locally available Sample Superstore CSV file.
